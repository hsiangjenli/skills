# 逐字稿轉 Markdown 筆記

請讀取 `transcription/<stem>-ref.txt`，依下列流程產生筆記，存為 `note/<stem>-ai-note.md`。

## 流程

1. 閱讀逐字稿，找出核心主題、關鍵概念、人名、工具或專有名詞。
2. 若逐字稿提到的概念、名詞或背景資訊不夠完整，使用網路搜尋工具查證與補充，優先採用官方文件、原始論文或可信來源。
3. 撰寫筆記。逐字稿內容是主體；網路補充的內容必須放在「補充說明」標註，並在「參考資源」列出來源網址。
4. 無法查證的內容不要寫入。搜尋不到可靠來源時，略過補充，不要編造。

## 內容規則

- 只使用逐字稿與可查證的補充資料，不捏造數據、引言或人名。
- 中文與英文、數字之間加空白，例如「使用 Markdown」。
- 每個 H2 標題下先放一句話重點（以 `>` 引言呈現）。
- H2 最多 5 個；內容以段落、列點、表格或 Mermaid 圖擇一或組合，避免冗長列舉。
- 標題文字依模板，不要自行增減 Emoji。

## 輸出模板

```markdown
---
title: '{根據逐字稿擬定的標題}'

updated: '{YYYY-MM-DD，今天日期}'

- '{使用的模型名稱}'
- ' & Hsiang-Jen Li'
tags:
- '{關鍵詞1}'
- '{關鍵詞2}'
- '{關鍵詞3}'
toc: true
lang: zh-TW
---
```

## 輸出要求

- 只輸出最終 Markdown 內容到 `note/<stem>-ai-note.md`，不要附加說明文字。
- 不可刪除或重新命名模板中的 H1 標題（簡介、介紹、關鍵概念、重點回顧、延伸議題、參考資源）。
- 沒有補充資料時，刪除「補充說明」小節與「參考資源」中的網路來源，但保留 `[逐字稿]` 那一行。
